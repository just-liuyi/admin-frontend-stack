# 登录页

左右分栏：左边是品牌和会互动的插画小人，右边是登录表单；手机上只显示居中的登录卡片。

最后核实：2026-10-23（React 19.3、react-router 8.5、react-hook-form 7、zod 4.6、shadcn CLI 4.22.1）。
验证方式：`assets/login/` 的代码在真实工程里通过 `tsc -b` 和 `vite build`，用无头浏览器（Edge）走查了下文「交付检查」的 36 项；导航、页签的全部检查同时通过。

效果图（能看图时先看，按图实现）：`assets/previews/login-desktop.jpg`（电脑）、`login-mobile.jpg`（手机）、`login-moods.jpg`（小人在输入用户名、输入密码、显示密码、登录失败时的反应）。小人的颜色每次随机，图里只是其中一种。

## 直接用现成代码

| 文件 | 放到 | 作用 |
|---|---|---|
| `login.tsx` | `src/pages/login.tsx` | 登录页：左右分栏、两种登录方式、表单校验 |
| `login-mascots.tsx` | `src/components/` | 插画小人：跟随鼠标、对输入作出反应、随机配色 |
| `auth-api.ts` | `src/api/auth.ts` | 登录接口。**这是假实现**，接真实后端时只换函数内部，保持函数名和返回值 |
| `auth-store.ts` | `src/stores/auth.ts` | 登录态（Zustand `persist`）+ `safeRedirect()` |
| `App.tsx` | `src/App.tsx` | 应用根：登录守卫、登录后回跳、应用主题 |
| `login-tokens.css` | 合并进全局 CSS | 小人配色 token 和三个动画 |

还需要：`npx shadcn@latest add tabs field input button sonner`（登录成功的"欢迎回来"提示用 Sonner，并按 `patterns.md` 改掉它对 next-themes 的依赖），以及 `react-hook-form`、`@hookform/resolvers@5`、`zod@4`（安装注意事项见 `stack.md`）。入口用 `assets/shared/main.tsx`（含 `Toaster`）。新项目的完整步骤见 `quickstart.md`。
品牌名和 Logo 改 `login.tsx` 顶部的 `APP_NAME` 和 `Brand` 组件。
另外要按 `patterns.md` 改好 `components/ui/tabs.tsx` 并在 `main.tsx` 调用 `trackInputModality()`（`assets/shared/input-modality.ts`），否则点击登录方式页签时会出现灰色焦点框。

## 布局

| 区域 | 内容 |
|---|---|
| 左栏（≥1024px 才显示，占约 52%） | 主色浅渐变底；左上角 Logo + 系统名；三个缓慢漂浮的圆；底部居中的插画小人；最下方版权 |
| 右栏 | 标题"欢迎回来" + 一句说明；下划线样式的页签（账号密码登录 / 手机验证码登录）；表单 |
| 手机（<1024px） | 不显示插画；浅主色渐变背景上一张居中的白色卡片，卡片顶部显示 Logo |

- 标题、说明、按钮文字都用中文；"登 录"按钮两字之间留空格，是常见的中文按钮写法。
- 页签下划线和选中文字用主色；深色模式下也要显式写 `dark:data-active:text-primary`，悬停时也要保持主色（见「已踩过的坑」）。
- 页签没有焦点框：用键盘切换时下划线从 2px 加粗到 4px 表示焦点。
- 两种登录方式的表单叠放在同一格（`forceMount` + 隐藏非当前的），区域高度固定，切换时整块不会上下跳。

## 插画小人

四个纯 CSS 画的几何小人（高紫方块、深色方块、半圆、圆顶条），不用图片。

| 状态 | 什么时候 | 反应 |
|---|---|---|
| 平时 | 没有焦点在输入框 | 整体朝鼠标方向歪（最多 6°），眼珠跟着鼠标转 |
| 看表单 | 焦点在用户名、空密码框、手机号、验证码 | 全体朝表单歪头、眼睛看向右边 |
| 偷看 | 密码框有焦点且已输入内容 | 最高的小人伸长 40px、歪 18° 凑过去看 |
| 回避 | 点了"显示密码"且密码不为空 | 全体站直，眼睛看向左上方 |
| 难过 | 登录失败 | 一起摇头，眼睛往下看，1.4 秒后恢复 |

- **随机配色**：四种颜色（主色、深灰、橙、黄）每次打开页面随机分配给四个小人，同一次访问内不变（只在组件首次挂载时洗牌一次）。
- **五官颜色跟着身体深浅走**：深色身体（主色、深灰）上的点状眼睛和嘴用白色，浅色身体（橙、黄）上用深色；白眼球加一圈淡描边，落在浅色身体上也看得清。随机配色必须做这一条，否则深色身体上的黑眼睛会看不见。
- 四个小人错开时间眨眼，避免同时闭眼。
- 配色是 `icons-and-graphics.md`"插画只用主色 + 一个点缀色"规则的**例外**，只限登录页小人；`--mascot-1` 跟随主色，换品牌色时自动变。
- 系统开启"减少动态效果"时：不跟随鼠标，不眨眼、不漂浮、不摇头。
- 整个插画 `aria-hidden`，对屏幕阅读器不可见。

## 表单

账号密码：
- 用户名、密码都必填（标签前红色 `*`，`aria-hidden`）；输入框左侧有图标。
- 密码框右侧的眼睛按钮切换显示 / 隐藏，有 `aria-label` 和 `aria-pressed`；按下时 `preventDefault`，焦点留在密码框里。
- `autoComplete`：用户名 `username`，密码 `current-password`，让浏览器的密码管理能正常工作。

手机验证码：
- 手机号校验 `^1[3-9]\d{9}$`（中国大陆号码），验证码 6 位数字。
- "获取验证码"先只校验手机号，通过后发送并开始 60 秒倒计时（按钮显示"N 秒后重发"并禁用）。
- 验证码框 `autoComplete="one-time-code"`，手机上能自动填入短信验证码。

通用：
- React Hook Form + Zod，`<form noValidate>`，错误在字段下方用中文显示。
- 提交中按钮显示"登录中…"并禁用；接口返回的错误（账号或密码错误、验证码错误）显示在表单顶部的红色提示条里（`role="alert"`）。
- 切换登录方式时，"显示密码"状态复位。

## 登录流程（守卫、回跳、退出）

- 未登录访问任何页面 → 跳到 `/login?redirect=原地址`。
- 已登录访问 `/login` → 跳到回跳地址（没有就去首页）。
- **登录成功后的跳转只在 `App.tsx` 里做一次**：登录页只负责写入登录态，`App.tsx` 发现"已登录且在登录页"时跳走。
- 回跳地址只接受站内路径（以 `/` 开头且不以 `//` 开头），`?redirect=//evil.com` 一律回首页，防止被利用跳到钓鱼网站。
- 登录成功：清空页签（只留首页），提示"欢迎回来，姓名"。
- 退出登录（右上角个人菜单）：清除登录态、清空页签、回到登录页。
- 主题在 `App.tsx` 最外层应用（`useApplyTheme()`），这样登录页也支持深色模式。

真实项目里还需要：请求层统一拦截 401 → 清登录态 → 跳登录页并带回跳地址（见 `admin-layouts.md`）；token 的存放与刷新按后端方案来，本文的演示登录态只存了用户信息。

## 已踩过的坑

1. **登录后跳错页面。** 登录页自己 `navigate(redirect)`，同时 `App.tsx` 的"已登录在登录页就跳首页"也触发，后者覆盖了前者，用户总被带回首页。跳转只能有一处。
2. **登录页不支持深色。** `useApplyTheme()` 放在后台外壳里，登录页不在外壳里所以没生效。必须放在应用最外层。
3. **随机配色后看不见脸。** 浅色身体上的黑点眼睛，换到深灰身体上就和身体融为一体。五官颜色要按身体深浅切换。
4. **所有小人同时闭眼。** 眨眼动画相同就会同步，截图正好拍到时像集体闭眼。每个小人设不同的 `animation-delay`。
5. **页签没对齐标题。** shadcn 的 `TabsList` 自带 3px 内边距，下划线样式下要加 `p-0`。
6. **深色下选中的页签变白字。** shadcn 的 Tabs 有 `dark:data-active:text-foreground`，会盖掉 `data-active:text-primary`，深色模式要再写一遍主色。
7. **浏览器校验气泡。** 忘了 `noValidate` 会先弹浏览器自带的提示（见 `patterns.md`）。
8. **切换登录方式时整块上下跳。** 账号密码表单（含演示账号提示）高 259px，验证码表单高 223px，右栏又是上下居中，切换一次标题就跳 18px。两个表单叠放在同一格解决。
9. **点击页签出现灰色"气泡"。** 页面刚打开时第一次鼠标点击页签，浏览器也当成键盘操作显示焦点框，下划线样式下框还被截掉一截。焦点框改为只在键盘操作时显示（全站 Tabs 的通用改法见 `patterns.md`）；登录页的页签再进一步去掉框，用加粗下划线表示焦点。
10. **点完页签文字变黑。** shadcn Tabs 的悬停色盖掉了选中的主色，鼠标停在刚点的页签上时文字是黑的。加 `data-active:hover:text-primary`。

## 交付检查

下面 36 项在参考实现上已全部实测通过：

- 未登录访问内页跳到登录页并带回跳地址；登录成功回到原页面；已登录再访问登录页跳回首页；回跳地址是外站时回首页
- 小人：鼠标在左向左歪、在右向右歪；眼珠跟着鼠标；点进用户名看向表单；点进空密码框不偷看；输入密码时偷看；显示密码时站直回避；登录失败摇头低头、1.4 秒后恢复
- 显示密码后变成明文且焦点仍在密码框
- 随机配色：12 次打开出现多种组合且四色各用一次；深色身体上五官是白色、浅色身体上是深色；同一次访问中颜色不变
- 提交中按钮"登录中…"且禁用；账号密码错误在表单内提示；空提交显示中文必填提示
- 切换登录方式时标题和页签位置不变（电脑、手机各测一次）；点击页签后没有灰色焦点框；点完鼠标还停在页签上时文字仍是主色
- 登录后有"欢迎回来"提示、页签只剩首页和目标页；退出登录回到登录页且页签清空
- 短信：没填手机号就获取验证码时提示；获取后开始倒计时；验证码错误提示；正确验证码登录成功
- 手机端不显示插画只显示卡片、没有横向滚动；减少动效时小人不跟随鼠标
- 控制台没有运行时错误

## 未核实事项

- 图形验证码、登录失败次数限制：未实现（应由后端控制，前端只负责展示）。
- 手机号格式只支持中国大陆号码；海外号码需要加国家区号选择。
- 只在无头浏览器里测过，没有在真实手机上测试短信验证码自动填入。
