# 后台页面原型

后台页面高度同质化。生成页面时先判断属于哪种原型，再套用结构，不要每个页面重新发明布局。

## 目录
- 通用约定
- 应用外壳
- 列表页
- 表单（页面 / 抽屉 / 弹窗）
- 详情页
- 仪表盘
- 登录页与异常页
- 四种状态清单

## 通用约定

- 目录建议：`src/pages/<资源>/`（页面）、`src/components/`（跨页面业务组件）、`src/components/ui/`（shadcn，仅放 shadcn 组件）、`src/hooks/`（含 `useXxx` 查询 hook）、`src/stores/`、`src/lib/`。
- 每个页面顶部固定一个 PageHeader：标题 + 一句说明（可选）+ 右侧主操作按钮。
- 主操作每页只有一个主按钮（`variant="default"`），其余用 outline / ghost。
- 页面内容区不套多余的 Card；表格、表单本身就是主体。Card 用于仪表盘指标块和详情页分组。
- 文案默认中文，提示语简短，按钮用动词（"新增用户"，而非"确定"）。
- 所有可交互元素有 hover / focus-visible 状态；图标按钮必须有 `aria-label` 或 Tooltip。

## 应用外壳

结构：`SidebarProvider` → `AppSidebar` + `SidebarInset`（内含顶栏 + 内容区）。
**完整规则和验证过的代码见 `navigation.md`，搭外壳前必须先读它。** 要点：

- 侧边栏：顶部是 Logo 和收放按钮（同一行），下面是分组菜单；底部不放任何东西。顶部区域与顶栏同高、底线连成一条，分组之间用分隔线。
- 收放按钮在侧边栏顶部，不放在侧边栏底部，不做成菜单项。折叠模式用 `collapsible="icon"`。
- 折叠状态只由 `SidebarProvider` 管理（自动写 cookie），不要再存进 Zustand。
- 菜单最多两级；单级、分组、二级怎么选见 `navigation.md`。选中状态由当前路由决定。
- 顶栏：左侧面包屑（手机端前面加一个打开菜单的按钮），右侧依次是全局搜索（Command 面板，快捷键 `⌘K`）、通知、**个人入口（永远在最右）**。
- 个人入口：自动生成的 SVG 头像 + 下拉菜单（姓名邮箱、个人设置、切换主题、退出登录）。整个应用只有这一个用户菜单。
- 菜单配置做成一份数据（含 `title`、`url`、`icon`、`children`、`permission`），侧边栏、面包屑、路由守卫共用，避免三处各写一遍。
- 内容区：`p-4 md:p-6`，滚动发生在内容区而不是整页，顶栏保持固定。
- 页签栏：**默认开启**，在顶栏下方、一起吸顶；首页固定，右键和右侧 ⌄ 按钮提供 刷新 / 关闭 / 关闭左侧 / 关闭右侧 / 关闭其他 / 关闭全部；最多 10 个；切换时保留页面状态。详见 `tabs.md`。

## 列表页（最常见）

自上而下：PageHeader → 筛选栏 → 批量操作条（有选中行时出现）→ 表格 → 分页。

- **筛选栏**：关键字 Input + 2~3 个常用筛选（Select / 日期范围）+「重置」。筛选条件同步到 URL 查询参数，刷新和分享链接后状态不丢。条件多时收进「更多筛选」Popover/Sheet。
- **表格**：需要排序、筛选、分页或列管理时用 TanStack Table + shadcn Table；几行只读的静态数据直接用 shadcn Table。首列可选复选框；状态列用 Badge（语义色）；最后一列操作：1~2 个常用操作直接显示，其余收进 DropdownMenu。
- **分页**：服务端分页，显示总数、每页条数选择、页码。翻页用 `placeholderData: keepPreviousData` 避免闪烁。
- **增删改**：新增/编辑 → Sheet 或 Dialog（字段少）或独立页面（字段多）；删除 → AlertDialog 二次确认，说明后果；成功/失败 → Sonner。
- **批量操作**：选中后显示「已选 N 项」+ 批量按钮，危险批量操作同样二次确认。

## 表单（页面 / 抽屉 / 弹窗）

- 字段 ≤ 6 个：Dialog；7~15 个：右侧 Sheet；更多或分组复杂：独立页面，分 Card/分节。
- 单列布局为默认；字段多时桌面端用两列网格，移动端回落单列。
- 每个字段：Label + 控件 + 可选说明 + 错误信息（由 Zod 驱动）。必填项标记统一。
- 底部操作区：取消（outline）+ 提交（default）；提交中禁用并显示 Spinner，防止重复提交。
- 有未保存修改时离开页面/关闭抽屉，要提示确认。

## 详情页

- 顶部：返回 + 标题 + 状态 Badge + 操作按钮（编辑、更多）。
- 主体：基本信息用 Card 内的键值网格（两三列）；关联数据（日志、订单、成员）用 Tabs 分页签，每个页签内是一个小列表页。
- 长文本、JSON 用等宽字体 + 可复制按钮。

## 仪表盘

- 顶部一行 3~4 个指标卡（数值 + 同比/环比 Badge + 一行说明）。
- 其下 1~2 张图表（shadcn Chart：趋势用折线/面积，构成用柱状/饼图），再下是「最近记录」小表格。
- 时间范围切换放右上角，切换后所有图表联动。
- 图表配色用 shadcn 提供的 `--chart-1…5` 变量，不自行挑色；每张图要有标题、单位、空数据态。

## 登录页与异常页

- 登录：左右分栏，左边品牌 + 会互动的插画小人，右边账号密码 / 手机验证码两种登录方式；手机上只显示居中卡片。完整规则和验证过的代码见 `login.md`。
- 403 / 404 / 500：简洁插画或图标 + 一句说明 + 「返回首页」按钮。
- 登录过期：统一在请求层拦截 401，跳转登录并携带回跳地址。

## 四种状态清单

每个依赖数据的区域都要处理：

| 状态 | 做法 |
|---|---|
| 加载中 | Skeleton，形状与最终内容接近（表格用若干行骨架）；按钮级加载用 Spinner |
| 空数据 | 图标 + 一句说明 + 引导操作（"暂无用户，立即新增"）；筛选无结果时提示「清除筛选」 |
| 出错 | 区域内错误提示 + 「重试」按钮；不要只打 console |
| 无权限 | 隐藏或禁用无权限操作（并用 Tooltip 说明）；整页无权限走 403 页 |
